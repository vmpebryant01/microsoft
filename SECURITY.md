# Security and disclosure

Author: Paul Bryant

The scripts are read-only inventory examples. They have no production-supported release and have not been tested in a live environment.

If you find a security issue, use GitHub's private vulnerability reporting option for this repository if it is available. If that option is unavailable, open a public issue that only requests a private contact channel. Do not include exploit details, credentials, tokens, or unredacted infrastructure data in a public issue.

For ordinary defects and version mismatches, use the [report problem template](.github/ISSUE_TEMPLATE/report_problem.yml).
