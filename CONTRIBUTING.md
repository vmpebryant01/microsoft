# Contributing

Author: Paul Bryant

Reports of broken links, incorrect fields, version differences, and sanitized test results are welcome through GitHub issues. Include the report name, product version or build, relevant API response shape, and the smallest redacted example that shows the problem. Do not post credentials, tokens, tenant IDs, private IP addresses, hostnames, or unredacted inventory.

The repository is all rights reserved. Please do not submit code changes or documentation copied from another source unless reuse rights and contribution terms have first been agreed with Paul Bryant. A useful issue report does not grant permission to use third-party code.

Live test reports should identify the exact product version and environment type. A successful run on one deployment will be recorded as that deployment's evidence, not as universal compatibility.
